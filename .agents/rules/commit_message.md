# Git Commit Message Rule

Setiap kali melakukan commit git dan push:
- Gunakan bahasa Indonesia santai
- Maksimal 5 kata
- Tanpa tanda baca apapun (tidak boleh ada titik, koma, titik dua, tanda seru, kurung, dll)

Contoh yang benar:
- benerin error linter dashboard
- ubah judul jadi lebih singkat
- hapus semua subtitle tampilan
- update tabel dan tombol kasir
